Rational Functions and Their Domain

Definition: The domain of a rational function is the set of all valid Blank values that can be substituted into the function. For rational expressions, we exclude any value that makes the denominator equal to $0$.

Example 1.

Give the domain of each rational function as indicated.

    1. Set-builder notation

    2. Interval notation

  2. Give the domain of the rational function $f(x)=\cfrac{4x^{2}-8x+3}{x+3}$ using either set-builder or interval notation.

Simplifying Rational Expressions

Many times we need to simplify rational expressions so they are easier to work with in calculus. This is the same idea as simplifying a fraction like $\cfrac{24}{15}$.

So how would you simplify something like $\cfrac{(x+2)(x-1)}{x(x-1)}$?

We will have expressions more like this though: $\cfrac{x^{2}-5x+6}{x^{2}-9}$.

It is important to remember one thing: you can ONLY cancel Blank; terms that are added/subtracted cannot be canceled (unless it is the entirety of the term with what it’s being added to). Explore this in the space below.

Example .

Simplify the following rational expressions.

  1. $\cfrac{t^{2}-25}{2t-10}$

  2. $\cfrac{3x^{2}}{6x^{3}+5x^{2}}$

  3. $\cfrac{2x^{2}}{4x^{2}+6x^{3}}$

  4. $\cfrac{3x-6x^{2}}{3x}$

  5. $\cfrac{x^{2}-5x+4}{2x^{2}-7x-4}$

  1. $\cfrac{6y-18}{2y-6}$

  2. $\cfrac{x-9}{9-x}$

    Hint: try rewriting the order in the denominator first.

  3. $\cfrac{3x^{2}-3}{x^{2}+x-2}$

  4. $\cfrac{20-5x^{2}}{x^{2}+x-6}$

    Hint: try rewriting the numerator and factoring out a negative.

Multiplying and Dividing Rational Expressions

Steps

  1. If you are dividing, Blank the second fraction and change the division problem to a Blank problem.

  2. Blank all numerators and denominators to see what they are made of.

  3. Blank like factors from the numerators with like factors in the denominators.

  4. Blank the reduced fractions to end the problem.

Example .
