Adding and Subtracting Rational Expressions

Rational Expressions with Like Denominators

The easiest problems are the ones where the denominators already match. Think back to what you would do with fractions like $\cfrac{3}{8}+\cfrac{5}{8}$.

When denominators match, we simply add or subtract the Blank while keeping the denominator the same.

Example 1.

Add or subtract as indicated.

  1. $\cfrac{3x}{5}+\cfrac{2x}{5}$

  2. $\cfrac{7x-2}{x+3}+\cfrac{4}{x+3}$

  3. $\cfrac{5x+1}{x-4}-\cfrac{3x-2}{x-4}$

  1. $\cfrac{2x^2}{x+1}-\cfrac{x^2}{x+1}$

  2. $\cfrac{6y-3}{y-2}+\cfrac{2y+5}{y-2}$

The Least Common Denominator

Recall how you combine fractions with unlike denominators such as $\cfrac{3}{8}+\cfrac{5}{6}$.

To combine these fractions we first determine the least common denominator (LCD).

Steps for Finding the Least Common Denominator

  1. First, Blank completely each denominator so you can see all the components.

  2. For common factors, only put Blank of each factor into the LCD.

  3. For any factors that are unique to a particular denominator, place Blank of these factors into the LCD so each original denominator divides Blank into the LCD.

Example 2.

Find the LCD of the following fractions. Then rewrite each fraction so they have that common denominator.

  1. $\cfrac{1}{x}$ and $\cfrac{1}{x+3}$

  2. $\cfrac{1}{x^2}$ and $\cfrac{1}{x}$

  3. $\cfrac{1}{x-2}$ and $\cfrac{1}{x^2-4}$

Extra Practice

Find the LCD of the following denominators.

  1. $x$ and $x+5$

  2. $x^2$ and $x$

  3. $x^2-9$ and $x+3$

  1. $x^2-4$ and $x^2-9$

  2. $x+4$, $x-4$, and $x^2-16$

Adding or Subtracting Rational Expressions with Unlike Denominators

To add or subtract rational expressions with different denominators, follow these steps.

  1. First find the Blank for all denominators present in the problem.

  2. Rewrite each fraction so it has the LCD by Blank the numerator and denominator by any missing factors.

  3. Add or subtract the numerators while keeping the LCD as the denominator.

  4. Finally, check whether the result can be Blank.

Example 3.

Add or subtract as indicated.

  1. $\cfrac{1}{x}+\cfrac{1}{x+2}$

  2. $\cfrac{2}{x}+\cfrac{3}{x^2}$

  1. $\cfrac{x}{x-3}-\cfrac{2}{x+3}$

  2. $\cfrac{2}{x^2-9}+\cfrac{3}{x+3}$
