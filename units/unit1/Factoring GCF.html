Greatest Common Factor (GCF)

One of the basic components of factoring is finding the GCF (or Blank) for a set of terms.

Example 1. Find the GCF.

  1. Find the GCF of $9$ and $21$.

  2. Find the GCF of $15$, $30$, and $45$.

  3. Find the GCF of $12x^2$ and $36x$.

  4. Find the GCF of $50y^2$ and $20y^5$.

  5. Find the GCF of $8xy^4$, $20x^2y^4$, and $28xy^3$.

Factoring Out the GCF

Example 2. Factor the following by factoring out the GCF.

  1. $9b^2 + 6$

  2. $7x^2 + 14x^3$

  3. $20y^2 - 4y^3 + 12y^4$

  4. $3z - 21xz^4$

  5. $6a - 7b^2$

  6. $-2x^2y - 4xy + 10y$

  7. $3a + 5ya$

  8. $3(x+7) + 5y(x+7)$

  9. $4x(x+1) - (x+1)$

Optional application: Factoring is often used to simplify formulas and highlight what is “shared.”

Example: If a cost model is $C(x)=12x+36$, factoring gives $C(x)=12(x+3)$, which shows a base “$+3$” added to each unit $x$.

Factoring by Grouping

If you ever have a polynomial that has Blank terms, it is often good to try Blank to factor it down.

Example 3. Factor the following by grouping.

  1. $xy - 5y + 3x - 15$

  2. $y^3 + 6y^2 + 4y + 24$

  3. $m^2n^2 + m^2 - 2n^2 - 2$

  4. $xy + 2x - y - 2$
