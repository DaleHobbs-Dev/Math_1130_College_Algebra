Review of Exponent Properties

Here is a list of common exponent rules that you will encounter in the course.

Rule 1: Product of Powers

$a^m \cdot a^n = a^{m+n}$

Rule 2: Quotient of Powers

$\dfrac{a^m}{a^n} = a^{m-n}$

Note — subtract $m$ and $n$ from each other. Then decide whether remaining factors belong in the numerator or denominator.

Example 1. Simplify the following expressions using either Rule 1 or Rule 2 (or a combination of both).

  1. $y^3 \cdot y^8$

  2. $m^3 \cdot m \cdot m^5$

  3. $(8x^2y)(6xy^8)$

  4. $\dfrac{x^8}{x^3}$

  5. $\dfrac{p^3}{2p^9}$

  6. $\dfrac{8v^4}{2v^{16}}$

  7. $\dfrac{7x^3y^9}{14x^6y^4}$

  8. $\dfrac{(-3m^3v^2)(-6mv^6)}{2m^5v^4}$

Rule 3: Negative Exponents

$a^{-m} = \dfrac{1}{a^m}$

Or equivalently: $\dfrac{1}{a^{-m}} = a^m$

Example 2. Simplify each expression below using positive exponents in your answer.

  1. $\dfrac{1}{y^{-4}}$

  2. $\dfrac{5}{x^{-8}}$

  3. $p^{-7}$

  4. $\dfrac{3m^{-3}}{2}$

  5. $\dfrac{5v^{-4}}{7b^{-8}}$

  6. $\dfrac{(7n)^{-4}}{9}$

Rule 4: Zero Power Rule

$a^0 = 1$ (for $a \ne 0$)

Example 3. Simplify.

  1. $7^0$

  2. $x^0$

  3. $\left(\dfrac{8x^{19}}{17y^{48}}\right)^0$

Rule 5: Power to a Power

We need one other rule when working with exponents that is really helpful. Observe the following:

$ (x^3)^2 $

This gives us an idea how the rule will work:

$(a^m)^n = a^{mn}$

Moreover, you can expand this rule in the case there are multiple factors inside the parentheses being raised to the same power. Simplify the following to see how that works:

$(2x^4)^3$

You can apply it to fractions as well:

$\left(\dfrac{x^3}{y^2}\right)^4$

Example 4. Simplify the following using only positive exponents in your answer.

  1. $(y^8)^4$

  2. $(2b^6)^4$

  3. $(3m^2n^5)^3$

  4. $\left(\dfrac{y^{-7}}{x^{-10}}\right)^{-3}$

  5. $\dfrac{(-3x^5y)^2}{x^7y^3}$

  6. $\left(\dfrac{2a^3b}{-4a^4b^2}\right)^5$
