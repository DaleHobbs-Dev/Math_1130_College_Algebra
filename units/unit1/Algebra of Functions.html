Algebra of Functions

Introduction

Definition: The function notation $(f+g)(x)$ is defined as $f(x)+g(x)$.

Definition: The function notation $(f-g)(x)$ is defined as $f(x)-g(x)$.

Definition: The function notation $(f\cdot g)(x)$ is defined as $f(x)\cdot g(x)$.

Definition: The function notation $\left(\dfrac{f}{g}\right)(x)$ is defined as $\dfrac{f(x)}{g(x)}$.

Example 1.

Let functions $f$ and $g$ be defined as follows: $f(x)=x+3$ and $g(x)=x-5$. Find the following functions: $(f+g)(x)$, $(f-g)(x)$, $(f\cdot g)(x)$, and $\left(\dfrac{f}{g}\right)(x)$.

  1. $(f+g)(x)$

  2. $(f-g)(x)$

  3. $(f\cdot g)(x)$

  4. $\left(\dfrac{f}{g}\right)(x)$

Example 2.

Let functions $f$ and $g$ be defined as follows: $f(x)=x+3$ and $g(x)=x-5$. Find the following values: $(f+g)(3)$, $(f-g)(-2)$, $(f\cdot g)(4)$, and $\left(\dfrac{f}{g}\right)(8)$.

  1. $(f+g)(3)$

  2. $(f-g)(-2)$

  3. $(f\cdot g)(4)$

  4. $\left(\dfrac{f}{g}\right)(8)$

Example 3.

Let functions $f$ and $g$ be defined as follows: $f(x)=2x^2-x+3$ and $g(x)=-2x+1$. Find the following: $(f+g)(x)$, $(f+g)(2)$, $(f-g)(x)$, $(f-g)(-2)$, $(f\cdot g)(x)$, and $(f\cdot g)(-1)$.

  1. $(f+g)(x)$

  2. $(f+g)(2)$

  3. $(f-g)(x)$

  4. $(f-g)(-2)$

  5. $(f\cdot g)(x)$

  6. $(f\cdot g)(-1)$
