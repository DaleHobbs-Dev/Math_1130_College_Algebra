Polynomial Terminology

Definition: A Blank is a number or the product of a number and one or more variables raised to powers.

Definition: A Blank is the numerical factor of a term.

Terms and Coefficients

Terms Coefficients
$-3xy^2$ Blank
$-z^3$ Blank
$x$ Blank
$4$ Blank
$\dfrac{w^2 y^4}{7}$ Blank

Definition: A Blank is a finite sum of terms in which all variables are raised to non-negative integer powers (0, 1, 2, 3, etc.) and no variables appear in any denominator.

There are three common types of polynomial names that are very good to be acquainted with in this course.

  • A Blank is a polynomial consisting of one term.
  • A Blank is a polynomial consisting of two terms.
  • A Blank is a polynomial consisting of three terms.

Definition: The Blank of a term is the sum of the exponents on the variables contained in the term.

Example 1. Find the degree of each term below.

  1. $2x^3$

  2. $x$

  3. $7x^2y^3$

  4. $9$

Definition: The Blank of a polynomial is the largest degree of a single term in the polynomial.

Example 2. Tell if the following polynomials are monomials, binomials, or trinomials and then tell the degree of the polynomial.

  1. $4x^5 + 7x^3 - 1$

  2. $6y + y^3$

  3. $-2xy^2 + 5x^3y - 8xy + 4$

Adding and Subtracting Polynomials

Definition: Blank are terms that contain exactly the same variables raised to exactly the same powers.

Adding or subtracting polynomials is all about combining like terms. Let’s try some examples below.

Example 3. Simplify the following by combining like terms.

  1. $10x^3 - 12x^3 - 3x$

  2. $-6ab + 2a + 12ab - a$

Example 4. Add the following polynomials.

Add

$14x^4 - 6x^3 + x^2 - 6$ to $x^3 - 5x^2 + 1$

Example 5. Subtract the following polynomials.

Subtract

$9x^4 + x^2 - 18$ from $7x^4 - 8x^2 + x$

Example 6. Add or subtract the polynomials. Write the answers in simplest form, using descending order.

  1. $(-5x + 7x^2 + 13) + (9x - 50 + 4x^2)$

  2. $(5w^5 + 9w^2 - 3) - (8w^5 - 7w^2 + 11)$

  3. $(-5a^4 + 8a^2 - 9) - (6a^3 - a^2 + 2)$
