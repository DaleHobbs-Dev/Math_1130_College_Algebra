What is a Relation and a Function?

A Blank is any set of ordered pairs, $(x, y)$. The set of all possible inputs, or the collection of $x$-values in the ordered pairs, makes up the Blank. The set of all possible outputs, or the collection of $y$-values in the ordered pairs, together make up the Blank.

A Blank is a relation with a one-to-one correspondence from $A$ to $B$, where each element of $A$ is paired with one, and only one, element of $B$. Here, $A$ is the Blank of the function, and $B$ is the Blank. In other words, a relation is a function if each input corresponds to exactly one output.

Function Notation

For the function $y = f(x)$:

  • $f$ is the name of the function.
  • $x$ is the domain value (input).
  • $f(x)$ is the range value $y$ corresponding to the value of $x$ (output).

We read $f(x)$ as “$f$ of $x$” or “the value of $f$ at $x$”.
