Solving Quadratics Using Completing the Square

Recognizing Perfect-Square Trinomials

Before solving quadratic equations by completing the square, it helps to notice how certain trinomials factor into a perfect square.

Key Idea

Now suppose we had the equation

\[ x^2+8x+16=9 \]

Since the left side factors as a perfect square,

\[ x^2+8x+16=(x+4)^2, \]

the equation becomes

\[ (x+4)^2=9, \]

and then we can finish by using the square root principle.

The Basic Premise

This is the basic premise behind completing the square: we want the left side of the equation to become a perfect square trinomial so that it can be factored into a binomial square and solved using square roots.

The “Magic Number” Pattern

In a trinomial of the form \(x^2+bx+\text{something}\), the number we add is based on taking half of the coefficient of \(x\) and squaring it.

How to Complete the Square

Steps

  1. Move any constants to the right side so that the left side has only the quadratic and linear terms.
  2. Add a \(+\) ____ and a \(+\) ____ to both sides to make room for the “magic number.”
  3. Find the magic number that completes the square on the left side, and add it to both sides.
  4. Factor the left side as a perfect square and simplify the right side.
  5. Finish by using the square root principle.

Helpful Shortcut

If the left side is \(x^2+bx\), then the number you add is \(\left(\frac{b}{2}\right)^2\)
