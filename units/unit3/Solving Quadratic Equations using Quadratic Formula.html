Solving Quadratic Equations using the Quadratic Formula

What Is a Quadratic Equation?

Definition

A quadratic equation is any equation that can be written in the form

\[ ax^2+bx+c=0 \]

where \(a\neq 0\).

Note

Why can \(a\) not be \(0\)? What would happen? We would just have \(bx+c=0\), which would be a linear equation. Quadratic comes from the fact that the highest variable power is \(2\).

Note

Quadratic equations can have at most \(2\) solutions, but they can also have \(1\) solution or even \(0\) real solutions. This is best seen when graphing.

Quadratics of the Form \(ax^2+c=0\)

If the linear \(bx\) part is missing from the quadratic, these are some of the simpler ones to solve. You can move everything away from the \(x^2\) term and then, last, take the square root of both sides. There is a trick, though, to ensure you get both the positive and negative square roots as solutions: whenever you take the square root of both sides of an equation, remember to include both the \(+\) and \(-\) versions of the root.

Examples of solutions using the square root property: \(x^2=16\) would give \(x=\pm 4\). A problem like \(x^2=11\) would give \(x=\pm \sqrt{11}\).

Example

Solve the following quadratic equations using the square root property.

  1. \[ x^2=81 \]

  2. \[ x^2=23 \]

  3. \[ x^2-20=0 \]

  1. \[ 2x^2-10=0 \]

  2. \[ (x+6)^2=4 \]

  3. \[ 2(x-11)^2+5=21 \]

Quadratics of the Form \(ax^2+bx+c=0\)

Any other quadratic, you will have to solve with one of the following methods given in the order you should try them:

Suggested Order of Methods

1st — Try to factor first! If you can get it into factors, these are the nicest ones, and then you set each factor equal to zero in order to finish solving.

2nd — If you can’t factor, then identify the \(a\), \(b\), and \(c\) values and use the quadratic formula, a formula you SHOULD memorize.

\[ x=\frac{-b\pm\sqrt{b^2-4ac}}{2a} \]

This formula is powerful in that it will solve any quadratic equation, no matter what its constants are.

3rd — Completing the square. In practice, there is no step you will try after step 2 in this section, but there is another method that will solve any quadratic equation: completing the square. We mention it here because it has practical uses later in Calculus.

Example

Solve the following quadratic equations using the Quadratic Formula.

  1. \[ x^2+7x+4=0 \]

  2. \[ x^2-13=5x \]

  3. \[ 10m^2-2m=3 \]

  4. \[ \frac{x^2}{10}-\frac{x}{5}=1 \]

    (Hint: get rid of fractions to make this simpler to deal with.)
